## 1. Optimum Range 与音域限制

### 1.1 什么是 Optimum Range

**Optimum Range**（最佳音域）是歌声合成引擎官方标注的声库最适合演唱的音高范围。它由以下因素决定：

- **采样层数 (Stationary Layers)**: 录制时覆盖的琴键数量
- **引擎兼容性**: 声线特征与合成引擎的匹配度
- **音域重叠**: 多层采样之间的交叉过渡质量

**注意**: Optimum Range **不是**声库能发出的最高/最低音，而是"音质最佳"的范围。超出该范围并不意味着不能发声，而是会出现各种缺陷。

### 1.2 音域外的典型表现

| 方向 | 超出程度 | 表现 |
|------|----------|------|
| **高音域外** | 略超 | 音色变薄、力量下降、轻微失真 |
| **高音域外** | 远超 | 音质崩解 (Tone Collapse)、噪音环 (Noise Loop)、刺耳 |
| **低音域外** | 略超 | 音色模糊、辅音不清、类似低语 |
| **低音域外** | 远超 | 采样拉伸变形、元音听不清、机械感强烈 |

### 1.3 Optimum Range 的参考价值

| 软件 | 标注位置 | 典型范围示例 |
|------|----------|-------------|
| VOCALOID | 官方产品页 / Fandom Wiki | Miku V2: A3~E5 / KAITO V1: 未标注（极小） |
| Synthesizer V | 官方文档 | AI 歌手通常 3-4 个八度 |
| UTAU | 音源作者标注 | 取决于录音者音域 |
| CeVIO | 官方产品页 | 东北ずん子: F♯3~G♭4 |

## 2. 常见缺陷类型

### 2.1 音质崩解 (Tone Collapse)

**现象**: 超出 Optimum Range 后，声线特征突然消失，音色变得扁平、无辨识度。

**原理**: 引擎将采样拉伸/压缩到目标音高时，维持音色特征的共振峰被拉伸变形，导致"声音骨架"丢失。

**典型实例**:
- Megurine Luka V2: 高音区变薄变弱，难以达到女高音范围
- Megpoid (GUMI) V2: 高音超过 Mezzo-Soprano 后背景噪音明显，形成 Noise Loop
- Kagamine Len V4 English: 高音区缺乏音色，偶尔随机切换到类似 Luka V4x English 的音色

### 2.2 噪音环 (Noise Loop)

**现象**: 固定音高附近出现持续的背景噪音或嗡嗡声，与音符同时存在。

**原理**: 声库的 Stationary Layer 在该音高处采样不足，引擎填充时使用了低质量的底层噪音样本。

**典型实例**:
- Megpoid V2: 高音区 G3 附近开始噪音环，GEN 40 以上更明显
- ARSLOID V4: 大量缺失双音/三音采样，导致音素突然结束，产生硬边噪音

### 2.3 声区突变 (Register Switch)

**现象**: 在同一音域内，声音突然从"真声"切换到"假声"，或音色发生不自然跳跃。

**原理**: 声库同时录制了不同发声方式（真声/假声）的采样，在重叠音域处引擎可能随机选择不同层。

**典型实例**:
- kokone V3: 内置真声与假声范围重叠，在重叠区可能无预警切换
- VY2v3: Standard 与 Falsetto 声线重叠，编辑参数试图反向切换时声音不自然

### 2.4 辅音缺失/突兀 (Consonant Issue)

**现象**: 特定辅音在高/低音域被吞掉、爆破过度、或突然切断。

**原因**:
- 录音时未覆盖该音域的所有辅音-元音组合
- 引擎拉伸时辅音时长被错误计算
- 采样层在该区域重叠不良

**典型实例**:
- ARSLOID V4: 缺失大量双音/三音采样，辅音后元音衔接生硬
- Hatsune Miku V4 Chinese: 部分声母+"uo" 被误发为省略 "u" (如 "lo" 而非 "luo")
- Tohoku Zunko CeVIO AI: "e" / "a" 元音在某些情况下接近 "o" 音

### 2.5 鼻音/闷音问题 (Nasal / Muffled)

**现象**: 特定音域或全音域声音发闷、鼻音过重、高频缺失。

**典型实例**:
- Yuezheng Ling V3: 南方口音导致浓重鼻音，影响整体发音
- Otomachi Una V4: 部分元音 (尤其 "a" "o") 偶尔发闷
- Len V4 English: 整体音色缺乏质感，偏女性化

### 2.6 音色不一致 (Timbre Inconsistency)

**现象**: 同一音符反复出现时音色不同；或跨音阶时音色跳跃。

**原因**: 多层采样的边界处音色未平滑过渡，或引擎随机化过度。

## 3. 拆轨策略总览

### 3.1 为什么拆轨

拆轨（Track Splitting）是将原本单一歌声轨拆分为多个专用轨道，每个轨道：
- 使用不同的声库/声线
- 处理特定的音域范围
- 应用不同的参数/效果
- 负责特定的音乐元素（和声、气息、Whisper 等）

### 3.2 拆轨类型表

| 拆轨类型 | 目的 | 适用场景 |
|----------|------|----------|
| **音域拆轨** | 高音区用高音库，低音区用低音库 | 歌曲音域超过单个声库 Optimum Range |
| **XSY 辅助轨** | 用副声库补充主声库薄弱频段 | VOCALOID4+ 的 Cross-Synthesis |
| **气息轨** | 独立控制呼吸、叹气、尾音 | 需要精细呼吸控制的抒情曲 |
| **Whisper 轨** | 低语、耳语效果 | 氛围感、ASMR 风格、间奏 |
| **和声轨** | 三度/五度/八度和声 | 副歌增强、合唱效果 |
| **节奏加强轨** | 双重唱强调节奏感 | 摇滚、电子、快节奏 |
| **特效轨** | Growl、Distortion、Vocoder | 电子音乐、特殊效果 |

## 4. 按缺陷类型的拆轨方案

### 4.1 音域过宽 → 音域拆轨

**方案**: 将歌曲按音高切分为 2-3 个轨道

```
原始轨道: C3 ~ A5 (跨越 2.5 个八度)
拆轨后:
  轨道 1 (低音): C3 ~ G4 → 使用低音域强的声库 (如 VY2, KAITO)
  轨道 2 (高音): G#4 ~ A5 → 使用高音域强的声库 (如 Miku, Rin)
```

**切换点选择原则**:
1. 在 Optimum Range 的边界处切换
2. 避免在乐句中间切换，选择小节线或休止处
3. 两段轨道重叠 1-2 个音符用于交叉淡化 (Crossfade)

### 4.2 声区突变 → 分声区轨

**方案**: 将真声区和假声区分到不同轨道

```
歌曲: G3 ~ C5
拆轨后:
  轨道 1 (真声): G3 ~ B4 → 使用声库的真声采样区域
  轨道 2 (假声): C5 ~ C5+ → 使用声库的假声采样，或换用擅长高音的声库
```

**实例 (kokone V3)**:
- kokone 的真声和假声在 B4 附近重叠
- 在 B4 以下使用主轨
- 在 C5 以上切换到 "假声轨"，使用 kokone 的高音区（她知道会切换为假声）
- 或干脆换用 VY1v4 Power 等专门的高音声库

### 4.3 鼻音过重 → 和声掩盖轨

**方案**: 用其他声库的和声来掩盖主声库的鼻音频段

```
主轨 (鼻音声库): 演唱主旋律
副轨 (清晰声库): 在鼻音突出的音符上叠加三度和声
混音时: 主轨适当削减 1-2kHz，副轨适当提升同频段
```

### 4.4 辅音缺失 → 拆音辅助轨

**方案**: 将辅音和元音分离到不同轨道处理

```
主轨: 仅演唱元音主体 (Lyric 设为纯元音)
辅音轨: 提前 10-30ms 演奏辅音采样，力度增强 (VEL ↑)
```

**适用情况**:
- 低音域辅音被吞 (如 "ka" 的 "k" 听不到)
- 高音域爆破音过强 (如 "ta" 的 "t" 过于刺耳)
- 使用 UTAU 的拆音技术，结合 VEL 参数调整

### 4.5 音色单薄 → 双重唱 (Doubling) 轨

**方案**: 同一旋律用两个不同声库各唱一遍

```
轨道 1: 主声库 (如 Miku V4X Dark)
轨道 2: 辅助声库 (如 Miku V4X Solid)
混音: 轨道 1 居中，轨道 2 轻微偏移 (±10-15 cents) + 少量延迟 (10-30ms)
```

**效果**: 增加声音厚度、填补单一采样的频率空洞。

## 5. XSY (Cross-Synthesis) 弥补缺陷

### 5.1 XSY 原理

Cross-Synthesis 是 VOCALOID4+ 的功能，可以在两个声库之间按参数混合：
- `XSY` 参数 0~127: 0 = 纯主声库，127 = 纯副声库
- 副声库的音色特征"嫁接"到主声库的旋律上

### 5.2 用 XSY 弥补音域缺陷

```
场景: 主声库 (Miku V4 Original) 唱到 E5 以上音质下降
方案:
  副声库选择: Miku V4 Sweet (高音更好)
  在 E5 以上的音符: XSY = 80~110 (大量混入 Sweet 特征)
  在 C5 ~ E5 的过渡区: XSY = 30~60 (轻微混入)
  在 C5 以下: XSY = 0~20 (几乎不用)
```

### 5.3 XSY 弥补音色缺陷

```
场景: ARSLOID V4 音质低，音素结束生硬
方案:
  副声库选择: Fukase V4 (音色相近但更平滑)
  全局 XSY = 20~40: 软化 ARSLOID 的硬边
  注意: ARSLOID 的 Extend 声库 (Bright/Soft) 本身就是为 XSY 设计的
```

### 5.4 XSY 的局限性

- **仅限 VOCALOID4+**: V3 / V2 / UTAU / SV 不支持
- **需同引擎兼容**: 副声库通常需与主声库同语言、同引擎版本
- **非万能**: 如果两个声库都有相同缺陷，XSY 无法修复

## 6. 参数调整弥补缺陷

### 6.1 音域外参数急救

| 缺陷 | 参数 | 调整方向 | 说明 |
|------|------|----------|------|
| 高音变薄 | BRI (Brightness) | ↑ +10~+30 | 增强高频谐波 |
| 高音刺耳 | GEN (Gender) | ↓ -5~-15 | 降低共振峰频率 |
| 低音模糊 | BRI | ↑ +20~+40 | 增强清晰度 |
| 低音太闷 | BRE (Breathiness) | ↓ -10~-20 | 减少低频气息 |
| 噪音环 | DYN (Dynamics) | 局部降低 | 掩盖噪音区域 |
| 辅音不清 | VEL (Velocity) | ↑ +10~+30 | 增强辅音攻击 |
| 辅音过重 | VEL | ↓ -10~-20 | 弱化辅音 |
| 音区突变 | GWL (Growl) | 局部微调 | 用 Growl 掩盖切换点 |
| 整体不自然 | DYN | 画包络线 | 在缺陷区降低音量 |

### 6.2 音高曲线急救

| 缺陷 | 技巧 |
|------|------|
| 高音失真 | 在该音符加入微小颤音 (Vibrato)，掩盖引擎拉伸痕迹 |
| 低音发虚 | 音高曲线做轻微上翘 (Pitch Bend +10~+20 cents) |
| 音区切换突兀 | 切换点前加入 Portamento (滑音) 过渡 |
| 特定音高噪音 | 将该音符整体偏移 ±10~30 cents，避开引擎问题频段 |

## 7. 知名声库缺陷实例

### 7.1 VOCALOID 声库

| 声库 | 主要缺陷 | 拆轨/修复建议 |
|------|----------|--------------|
| **ARSLOID V4** | 采样量极低，音素生硬结束，音质商业声库中最低 | 必须用 XSY 搭配其他声库；或只用于特定摇滚风格 |
| **Megpoid V2** | 高音 G3+ 噪音环，GEN 40+ 触发 Ground Noise | 限制高音域使用；高音区换 GUMI V4 / Sweet |
| **Megurine Luka V2** | 高音薄弱，难以达到 Soprano | 高音换 Miku / Rin；或用 Luka V4X |
| **KAITO V1** | 极小声域，V1 引擎限制大 | 直接使用 KAITO V3 / V3 Whisper Extend |
| **Kagamine Len V4 ENG** | 高音缺音色，随机跳转到 Luka 音色 | 高音区换用 Len V4 JP 或其他男声 |
| **kokone V3** | 真声/假声重叠区无预警切换 | 拆轨：真声轨 + 假声轨，重叠区用参数锁定 |
| **Zhang Chuchu** | 适合范围极窄，出域后 Buggy | 严格限制在 Optimum Range 内使用 |
| **Yuezheng Ling V3** | 浓重鼻音，"xing" 发成 "xi-eng" | 叠加清晰声库和声；手动拆音处理 "ng" |
| **Hatsune Miku V4C** | 引擎噪音大，"uo" 声母丢失 | V4.0.1 版本修复部分问题；需大量后期降噪 |
| **SF-A2 miki** | 不同音区音色差异大 | 按音区拆轨处理 |

### 7.2 CeVIO / SV 声库

| 声库 | 主要缺陷 | 建议 |
|------|----------|------|
| **Tohoku Zunko CeVIO AI** | 相比 VOCALOID 版缺失一个八度，高音失真，元音"e/a"偏"o" | 严格控制在 F♯3~G♭4 内；使用 CeVIO 音高编辑功能补偿 |
| **Synthesizer V AI (通用)** | AI 歌手对极端参数可能产生 artifacts | 避免 tension > 1.5 或 breathiness > 80% 的极端设置 |

## 8. 拆轨工作流程

### 8.1 分析与规划

```
1. 确定歌曲的音域范围（最低音 ~ 最高音）
2. 对照主声库的 Optimum Range，标出"危险区域"
3. 列出歌曲中发现的缺陷类型
4. 选择拆轨策略（音域拆轨 / XSY / 和声 / 气息等）
5. 确定切换点（小节线、休止符、乐句边界）
```

### 8.2 执行拆轨

```
6. 复制主轨到副轨
7. 在副轨上删除不需要的音符（保留目标音域/效果）
8. 调整副轨声库/参数
9. 在切换点添加交叉淡化（音量包络渐变）
10. 试听检查衔接处是否自然
```

### 8.3 混音与微调

```
11. 调整各轨音量平衡
12. 对缺陷频段使用 EQ 补偿
13. 添加整体压缩/限制器统一音量
14. 检查相位问题（双重唱时尤其注意）
15. 导出试听，迭代微调
```
